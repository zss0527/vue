# vue2-cli

## vue2 init steps

```
npm install @vue/cli -g
vue --version
vue create project-name
```

## vue3 init steps
```aiignore
npm create vue@latest

```

## Project setup
```
pnpm install
```

### Compiles and hot-reloads for development
```
pnpm run serve
```

### Compiles and minifies for production
```
pnpm run build
```

### Lints and fixes files
```
pnpm run lint
```
